# OzvyX-AI (v1.0)

Собственная языковая модель (decoder-only Transformer) на 254 миллиона параметров, написанная с нуля. 
Обучение происходит на PyTorch (GPU Kaggle), а инференс (запуск) — на собственном C-движке прямо на Android (Termux).

## Что внутри
- `main.py` — точка входа. Автоматически компилирует C-движок и запускает чат.
- `engine.c` — инференс на чистом C (без PyTorch).
- `OzvyX-base-model/` — папка для весов (`model.bin`) и токенизатора (`tokenizer.json`).
- `model/bpe_tokenizer.py` — Python-обертка для BPE-токенизатора.

## Как запустить
1. Установите Termux и зависимости: `pkg install clang python -y`.
2. Скачайте или обучите модель (файлы `model.bin` и `tokenizer.json` в папку `OzvyX-base-model/`).
3. Запустите: `python main.py`.

## Обучение
Модель обучалась на 6 ГБ текста из FineWeb-2 (rus_Cyrl) и дообучалась на диалогах (SFT). 
Архитектура: 16 слоёв, 16 голов, эмбеддинг 1024, словарь 32000 токенов.
